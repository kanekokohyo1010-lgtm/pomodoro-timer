# 🍅 ポモドーロタイマー

シンプルなポモドーロ・テクニック タイマーです。インストール不要、1つの HTML ファイルで動作します。

## 使い方

`index.html` をブラウザで開くだけで使えます。

## 機能

- 作業 25分 / 小休憩 5分 / 長休憩 15分
- 円形プログレスリング表示
- ポモドーロカウント（4回ごとに自動で長休憩へ）
- 終了時のビープ音・ラスト5秒カウントダウン音
- キーボードショートカット対応

## キーボードショートカット

| キー  | 動作           |
|-------|----------------|
| Space | 開始 / 一時停止 |
| R     | リセット        |
